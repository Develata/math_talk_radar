# 10 — Selection and execution evidence

| ID | Requirement | Gate |
| --- | --- | --- |
| CI-001 | Include reverse consumers across all Cargo dependency kinds and conditions | hard |
| CI-002 | Unknown/public/shared changes and full profiles cannot silently select less | hard |
| CI-003 | Missing case definitions, mappings and shard handlers fail closed | hard |
| CI-004 | Empty, missing, skipped and duplicate test results never pass | hard |
| CI-005 | Missing, stale and altered execution evidence blocks final fan-in | hard |
| CI-006 | Wrong artifact digest or absent commit-specific review blocks release | hard |

Plan ref: `docs/plan/12_release.md`. Unit cases inject invalid catalogs, incomplete
graphs, missing tests and corrupted receipts. The tests shard additionally checks
every selected exact case binding against actual nextest inventory and JUnit.
Main and daily CI remain full; PR shadow records the proposed selection while
executing full. Live workflow errors are tested separately from source outages.

Cross-runner acceptance uses runtime executable/workspace paths. Release runs the
same musl bytes through static inspection, clean Ubuntu fixture scans, persistent
state reopen and checksum read-back. Full and release are different scopes:
baseline success never claims release-only attestation/review or live cases passed.
